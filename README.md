# San Marco Real Estate

Sito web luxury per San Marco Real Estate - oltre 25 anni di eccellenza immobiliare sulla costa adriatica.

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS + shadcn/ui
- Framer Motion
- Leaflet (mappe interattive)
- Overpass API (punti d'interesse)
- React Query

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```
